# 台架与实船验收清单

本清单尚未执行。离线自动化、安装包构建和原生启动结果见 [verification.md](verification.md)。每项记录软件提交、ROS/飞控/检测板版本、操作员、环境、实际结果和诊断包。

## 先决条件

- 先使用无桨/断推进动力台架，确认独立硬件停止与遥控器可用。
- 指定操作员和目标 sysid；确认 UDP/TCP router 拓扑，保存同步 QGC tlog、Jetson 和地面站 JSONL。
- 核查五端版本；实测使用主分支契约，如部署了其他修复另行记录。
- 软件控制的解锁、运动、泵和急停测试由操作员逐项确认。

## 台架

| 场景 | 操作与通过条件 |
|---|---|
| 身份与基础通信 | UDP/TCP/实际电台串口分别连接，飞控1与载荷191各自在线；错误sysid/compid不改变控制状态 |
| 26 字段 | 与 ROS/QGC 同时比对值与时间，四泵相对角与 Web 零点一致，-1及过期不显示有效测量 |
| 无 GPS 点采样 | 遮断定位后，载荷就绪仍可启动一次点采样；无导航模式误操作 |
| 去重 | 丢弃首个ACK/USVE1，使同身份同参数重传；ROS只创建一次物理attempt |
| 标准 ACK | 保留ACCEPTED、暂时阻断USVE1；地面站保持未确认关联执行，不显示成功 |
| USVE1 | 缺片、乱序、重复、晚到、旧session事件不结束新请求；恢复完整新事件可收敛 |
| 三类 STOP | 采样中分别验证31011全输出、31016走航及所属采样、31019分光；互不错误释放其他未知状态 |
| 普通命令等待 | 阻断31018回执期间发STOP；STOP仍发送，原START不继续重试 |
| 真实执行 | 暂停/恢复、归零、走航、分光与基线逐项核对真实检测板状态及错误；终态后新静止状态收敛 |
| 断链恢复 | 采样中断开GCS和router链路、重启应用；旧START不重发，原结果通过bridge恢复；不可恢复时保持unknown |
| ROS重启 | 原executor失效时不以重放START恢复；新的STOP确认与静止状态后允许合法新任务 |
| 分别停止 | 无桨条件测试推进急停与载荷全STOP，一路失败不显示两路确认；重连后新的STOP可完成确认 |
| 任务收发 | 上传含普通及采样项任务，飞控回读每个可执行项一致；丢包重试；拒绝、缺项和不一致明确失败 |
| ROS归档 | 新地面站及QGC各启动一次采样，数据中心均产生匹配attempt/window，CSV/ZIP文件可打开且字段完整 |
| 地图 | 在线浏览目标区域后断网，缓存区域与多级缩放可见；未缓存区域明确缺失 |
| Windows部署 | 干净Windows10/11安装、WebView2引导、卸载/重装、数据库与导出路径、无管理员运行 |
| Android部署 | ARM64安装、WebView/GPU、48px触控、UDP/TCP、HTTP、系统保存位置、取消和存储失败 |
| Android生命周期 | 转屏、前后台、锁屏、省电杀进程、网络切换；不重放START，unknown和恢复入口正确 |

## 受控水域

- 核实 GPS 固定质量、经纬度、航向及实际位置，地图 WGS84 对齐。
- 操作员在安全区域依次确认解锁、HOLD、GUIDED、RTL、AUTO；飞控状态变化与诊断一致。
- 执行带采样航线，核对42702 → USV_SMPL → ROS真实执行 → USV_DONE → 下个航点，超时/载荷断链进入飞控HOLD。
- AUTO中HOLD暂停、AUTO继续、停止任务与采样分别确认，任务进度符合飞控行为。
- 验证失联、低电、定位故障的现有飞控保护，记录所用参数，不为通过地面站测试关闭保护。
- 返回后核对轨迹、样本坐标、任务数量、归档数据与跨设备时钟证据。缺失中间日志的阶段标为未确认。

完成台架和现场项目后再决定生产使用范围。当前预发布产物只具备文档中列出的软件验证证据。
