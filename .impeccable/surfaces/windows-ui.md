# Windows 地面站 UI

MODE: Operate
FORM: 用户指定的 Minimalism 参考图；code-led。seed:2b69c9acdce58cbe。参考图已固定视觉方向。

## 产品与使用场景

操作员在 Windows 上观察无人船、规划航点、控制采样并追踪通信证据。地图占主要空间；真实状态、操作与回执要在同一工作区就近读取。

## 方向契约

- 参考图的白色侧栏、灰色选中行、细描边控件、无衬线字体和充分留白贯穿五个工作区。
- 浅色主题使用白色与中性灰；深色主题使用相同层级的炭灰，不引入其他主题。
- 桌面导航使用图标加文字的横向行，底部提供主题切换和设置。
- 驾驶舱使用一块地图及底部读数，右侧按功能平面分区。航线编辑与地图相邻；采样曲线、操作及记录保持独立层级；诊断按请求和阶段呈现证据。
- 颜色用于语义。蓝色标出航点、路径和焦点；红色标出停止与故障；确认成功可使用小面积绿色。
- 空状态来自真实设备快照。保留无连接、无数据、过期、未知和执行结果的区别，不添加示例读数。
- 首轮目标为 Windows NSIS。Android 构建已停止，CI 只保留 Windows。

## 验收

1280×720、1920×1080 的浅色与深色工作区无横向溢出；可切换主题并持久化；导航、航点编辑、确认框和设备准入保持原行为。Windows WebView2 实际启动与 Rust IPC 检查通过。随后由独立 reviewer 复核截图并由 documenter 更新设计 tokens。
